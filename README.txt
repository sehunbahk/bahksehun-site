BahkSeHun 포트폴리오 — 업데이트 설명서
==========================================

사이트 글과 작품 목록은 전부 content.js 한 파일에서 바꿉니다.
index.html은 건드리지 않아도 됩니다.


■ 폴더 구조
------------------------------------------
index.html          사이트 본체 (수정 X)
content.js          ★ 작품·사진·연락처 내용 (여기만 수정)
intro.mp4           홈 화면 인트로 영상
og.jpg              링크 공유 미리보기 사진 (1200x630)
images/
  poster.jpg        인트로 영상 뜨기 전 정지 화면
  film/작품폴더/      01.jpg, 02.jpg …
  commercial/작품폴더/
  photo/시리즈폴더/


■ 사진 준비 규칙
------------------------------------------
1. JPEG, 가로 2048px로 내보내기 (사진 시리즈는 긴 변 2000px)
2. 파일 이름은 01.jpg, 02.jpg, 03.jpg … (두 자리 숫자, 소문자 jpg)
3. 폴더 이름은 영어 소문자와 - 만 사용 (띄어쓰기·한글 X)
   예) film/new-short-film
4. 레터박스(검은 띠)는 잘라서 내보내기
5. 01.jpg가 목록의 대표 사진이 됩니다


■ 새 Film / Commercial 작품 추가하기
------------------------------------------
1. images/film/ 안에 새 폴더를 만들고 사진을 넣는다
2. content.js의 var FILM = [ 바로 아래에 아래 덩어리를 붙여 넣고 고친다
   (Commercial이면 var COMMERCIAL = [ 아래)

  {
    title: "작품 제목", year: 2027,
    director: "Director Name",
    note: ["제 00회 ○○영화제 상영"],
    ratio: "16/9",
    youtube: "",
    folder: "film/new-short-film", count: 10
  },

  · 맨 끝 },의 쉼표를 잊지 마세요
  · ratio: 사진 비율. 16/9, 4/3, 2.39/1 또는 "가로px/세로px" (예: 1920/804)
  · youtube: 주소가 https://www.youtube.com/watch?v=abc123 이면 "abc123"
             영상이 있으면 상세 페이지 맨 위에 재생 버튼이 생깁니다
  · note: 여러 줄이면 ["첫 줄", "둘째 줄"]. 없으면 []
  · count: 폴더 안 사진 장수
  · DP 이름은 자동으로 Bahk Se Hun. 바꾸려면 dp: "이름", 추가
  · 사진 비율이 섞여서 잘리는 게 싫으면 fit: "contain", 추가 (쏙독새 참고)
  · 목록 미리보기에서 사진 위치 조정: coverPosition: "center 75%",
    (두 번째 숫자가 클수록 사진 아래쪽이 보임)


■ 새 Photography 시리즈 추가하기
------------------------------------------
1. images/photo/ 안에 새 폴더를 만들고 사진을 넣는다
2. content.js의 var PHOTO = [ 바로 아래에 붙여 넣는다

  {
    title: "시리즈 제목",
    folder: "photo/new-series", count: 10,
    layout: ["1", "2 오른쪽", "3 4", "5", "6 7", "8 왼쪽", "9", "10 좁게"]
  },

  · layout 한 칸 = 한 줄
      "1"        1번 사진 전체 폭
      "3 4"      3번, 4번 나란히
      "2 오른쪽"  80% 폭 오른쪽 / "8 왼쪽" 80% 폭 왼쪽 / "9 좁게" 좁게 가운데
  · layout을 빼면 사진이 한 장씩 순서대로 나옵니다
  · 목록 칸(세로형)에서 대표 사진 위치 조정: coverPosition: "45% center",
    (첫 번째 숫자가 작을수록 사진 왼쪽이 보임)


■ 연락처 바꾸기
------------------------------------------
content.js 맨 위 var SITE = { … } 의 글자만 바꾸면 됩니다.


■ 확인하고 올리기
------------------------------------------
1. index.html을 더블클릭해서 브라우저에서 확인
2. 화면이 하얗게 비어 나오면 → content.js에 쉼표(,)나 따옴표(")가 빠진 곳이 있는 것
3. 문제없으면 바뀐 파일(content.js, 새 사진 폴더)만 사이트에 올리기
